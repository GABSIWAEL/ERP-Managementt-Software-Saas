# ERP System - Quick Reference Card

## 🚀 Getting Started (5 Minutes)

### Setup Database
```bash
# Option 1: Run script
bash setup-database.sh

# Option 2: Manual
psql -U postgres
CREATE DATABASE erp_system;
\q
```

### Start Application
```bash
cd erp
mvn clean install
mvn spring-boot:run
# Runs on http://localhost:8080
```

### First Login
```bash
# 1. Register admin user
POST /api/auth/register
{
  "username": "admin",
  "password": "pass123",
  "role": "ADMIN"
}

# 2. Login and get token
POST /api/auth/login
{
  "username": "admin",
  "password": "pass123"
}

# 3. Use token in headers
Authorization: Bearer <token_from_response>
```

## 📚 Current API Endpoints

### Authentication (Public)
```
POST   /api/auth/register          → Register new user
POST   /api/auth/login             → Get JWT token
```

### Departments (Role: ADMIN, HR)
```
GET    /api/departments            → List all
POST   /api/departments            → Create
GET    /api/departments/{id}       → Get one
PUT    /api/departments/{id}       → Update
DELETE /api/departments/{id}       → Delete
POST   /api/departments/{did}/assign-manager/{eid} → Assign manager
```

### Employees (Role: ADMIN, HR, MANAGER, ACCOUNTANT, EMPLOYEE)
```
GET    /api/employees              → List all
POST   /api/employees              → Create (HR, ADMIN)
GET    /api/employees/{id}         → Get one
PUT    /api/employees/{id}         → Update (HR, ADMIN)
DELETE /api/employees/{id}         → Terminate (ADMIN)
GET    /api/employees/department/{did} → By department
POST   /api/employees/{eid}/transfer-department/{did} → Transfer
GET    /api/employees/profile      → Current user profile
```

## 🔧 Quick Development Tasks

### Add New Endpoint

1. **Create DTO** (if not exists)
```java
@Data @Builder @NoArgsConstructor @AllArgsConstructor
public class MyDTO {
    @NotBlank private String name;
    @NotNull private Integer value;
    // getters/setters auto-generated by Lombok
}
```

2. **Add to Service Interface**
```java
public interface MyService {
    MyDTO create(MyDTO dto);
    MyDTO getById(Long id);
    void delete(Long id);
}
```

3. **Implement Service**
```java
@Service @Transactional @Slf4j
public class MyServiceImpl implements MyService {
    @Autowired private MyRepository repo;
    
    @Override
    public MyDTO create(MyDTO dto) {
        MyEntity entity = mapToEntity(dto);
        MyEntity saved = repo.save(entity);
        log.info("Created: {}", saved.getId());
        return mapToDTO(saved);
    }
    
    private MyDTO mapToDTO(MyEntity entity) {
        return MyDTO.builder()
            .id(entity.getId())
            .name(entity.getName())
            .value(entity.getValue())
            .build();
    }
}
```

4. **Create Controller**
```java
@RestController @RequestMapping("/api/my-resource")
@Slf4j @CrossOrigin(origins = "*")
public class MyController {
    @Autowired private MyService service;
    
    @PostMapping
    @PreAuthorize("hasRole('ADMIN')")
    public ResponseEntity<ApiResponse<MyDTO>> create(@Valid @RequestBody MyDTO dto) {
        log.info("Creating resource");
        MyDTO response = service.create(dto);
        return ResponseEntity.status(HttpStatus.CREATED)
            .body(ApiResponse.success(response, "Created successfully"));
    }
    
    @GetMapping("/{id}")
    @PreAuthorize("authenticated")
    public ResponseEntity<ApiResponse<MyDTO>> getById(@PathVariable Long id) {
        MyDTO response = service.getById(id);
        return ResponseEntity.ok()
            .body(ApiResponse.success(response, "Retrieved successfully"));
    }
}
```

}

## 📊 DTOs with Validation

```java
@Data @Builder @NoArgsConstructor @AllArgsConstructor
public class EmployeeDTO {
    private Long id;
    
    @NotBlank(message = "First name required")
    private String firstName;
    
    @Email(message = "Valid email required")
    private String email;
    
    @NotNull(message = "Salary required")
    @Positive(message = "Salary must be positive")
    private BigDecimal salary;
    
    @PastOrPresent(message = "Hire date must be past or today")
    private LocalDate hireDate;
}
```

## 🗃️ Entity Relationships

### ManyToOne (Many employees in one department)
```java
@Entity
public class Employee {
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "department_id")
    private Department department;
}

// In queries
List<Employee> emps = repo.findByDepartmentId(deptId);
```

### OneToOne (Employee linked to User account)
```java
@Entity
public class Employee {
    @OneToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "user_id")
    private User user;
}
```

### OneToMany (Department has multiple employees)
```java
@Entity
public class Department {
    @OneToMany(mappedBy = "department")
    private List<Employee> employees;
}
```

## 🚨 Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| **Connection refused** | Check PostgreSQL is running: `brew services list` |
| **Database not found** | Run: `createdb -U postgres erp_system` |
| **JWT error** | Check Bearer token format: `Authorization: Bearer <token>` |
| **403 Forbidden** | Verify user has correct role |
| **404 Not Found** | Check endpoint path and HTTP method |
| **400 Bad Request** | Validate JSON format and required fields |
| **Port 8080 in use** | Kill process: `lsof -i :8080` |
